# 群主接入指引（可直接发给想用的群主）

## 三步用起来

1. **注册平台账号**：打开平台地址 → 注册 → 登录
2. **绑定你的机器人**：去 [QQ 开放平台](https://q.qq.com) 复制你机器人的 `AppID` 和 `AppSecret`，在平台点"绑定机器人"粘贴。平台会自动校验凭证并加密保存。
   - 还没有机器人？开放平台免费注册创建，个人主体即可
3. **把机器人拉进群**：在群里添加机器人，然后到平台"管理 → 概览/自检"按提示开启群设置

## 群设置（群主操作，手机 QQ）

| 设置 | 位置 | 用途 |
|---|---|---|
| 获取群内全部消息 | 群设置 → 机器人 → 机器人可获取的群聊消息范围 | 关键词回复（不@也能触发）、广告监控 |
| 主动发言 | 群设置 → 机器人 | 欢迎新人、定时推送、监控告警通知 |
| 设为管理员 | 群设置 → 群管理 → 设置管理员 | 撤回广告、禁言、拉黑、入群审批 |

## 各功能需要什么权限

- 仅 @应答 / 关键词（仅@触发）/ AI 对话 / 抽签骰子抽奖：**拉进群就能用**
- 关键词（全量触发）/ 广告监控 / 活跃统计：开「获取群内全部消息」
- 欢迎新人 / 定时推送 / 举报转发：开「主动发言」
- 自动撤回 / 自动禁言 / 入群审批：**设为管理员**（撤回与禁言仅对普通成员生效）

## 群管理指令（可选，需平台授权）

在平台「群管自动化」页开启总开关、把群主的 user_openid 加入管理员名单后，群里可用：

| 指令 | 说明 |
|---|---|
| `/我的ID` | 显示你的 user_openid（加名单用） |
| `/禁言 @某人 分钟` | 禁言（单次可多人@，最长30天） |
| `/解禁 @某人` | 解除禁言 |
| `/踢人 @某人 [拉黑]` | 移出群聊，加"拉黑"则同步入黑名单（内邀接口） |
| `/拉黑 @某人` `/解除拉黑 @某人` | 群黑名单管理（内邀接口） |
| `/禁言列表` | 查看当前被禁言的成员和到期时间 |
| `/管理帮助` | 显示管理指令帮助 |

## 常见问题

- **绑定时提示凭证校验失败**：AppID/Secret 复制错了，或机器人被平台封禁；去开放平台核对
- **监控不生效**：消息范围没开"获取群内全部消息"，或关键词规则没保存/没启用
- **撤回没生效**：消息发出超过 2 分钟官方不允许撤回；或机器人不是管理员
- **禁言报无权限**：机器人不是管理员，或目标不是普通成员（管理员/群主禁不了）
- **定时推送偶尔没发**：官方限制每群每天最多 1000 条主动消息，达到上限当天不再发送
