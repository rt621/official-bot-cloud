# 运营手册（平台管理员）

## 上线检查清单

1. **配置**
   - `.env`：设强随机的 `SECRET_KEY`；`MASTER_KEY` 建议自己生成一次（留空则自动生成在 `data/.master_key`，**务必备份该文件**，丢了所有已绑机器人的 Secret 将无法解密）
   - `OPEN_REGISTRATION=false`：注册完自己的账号后关闭公开注册，改用"管理员代开账号"或按需临时打开
2. **HTTPS**：给用户用建议套域名 + HTTPS（Caddy/Nginx 反代 8000 端口即可；WebSocket 事件是机器人主动外连，不要求平台有公网 HTTPS，但用户访问页面建议上 HTTPS）
3. **备份**：定期备份数据库 + `data/.master_key`
4. **监控**：页面实例状态 + `data/uvicorn.log`；进程用 systemd/NSSM 托管自动拉起

## 你的责任边界（写在你自己的公告里）

- 平台代存用户 AppSecret（加密），泄露事故责任在平台——不要把服务器登录权交出去
- 机器人发出的内容以**用户自己的机器人**身份发出，但经平台调度：建议在用户协议里声明"内容由用户配置产生，用户自负"
- AI 回答已带输出过滤词表（`ai_chat.py` 的 `_BLOCKLIST_OUTPUT`），按需扩充
- 聊天原始内容**不落库**（只存统计和监控命中摘要），隐私承诺可以这么说

## 日常运维

| 场景 | 处置 |
|---|---|
| 实例状态 error | 看实例"运行日志"页签 + `status_detail`：常见为 Secret 错误（token 获取失败）、intent 无权限（4014，去开放平台申请）、机器人被封禁（100007/11265） |
| 用户说收不到群消息 | 让群主跑"自检"：确认消息范围=获取群内全部消息、机器人已在群 |
| 限频/429 | 平台每实例每群已做 1条/秒 节流和每日额度计数；仍 429 说明多实例共享官方侧配额，让用户减少推送频率 |
| 踢人报 11253 | 内邀白名单未开通，让用户找腾讯申请或降级为"禁言+拉黑（审批拒绝时）" |

## 平台能力与官方约束速查（2026-10 核对）

- Token 2 小时有效，平台自动刷新，无需人工干预
- 群被动回复：5 分钟窗口、每条消息最多回 5 次（平台已自动维护 msg_seq）
- 主动消息：每群每日 1000 条上限（平台计数器硬性拦截）
- 撤回窗口 2 分钟；禁言单次≤20 人、单成员≤30 天、不能禁群主/管理员
- 群管接口权限分层：禁言/入群审批=机器人是群管理员即可；**踢人、黑名单、成员列表=内邀白名单制**（错误码 11253，平台会返回友好提示，需联系 QQ 开放平台申请）
- 全员禁言：官方接口只能查询不能开启/关闭（群主手动设置）
- 频道（guild）相关接口未纳入本期平台功能

## 自动化规则引擎说明

- 「群管自动化」页的规则按"作用群"分群生效（`所有群` 兜底，指定群优先）
- 总开关关闭时所有规则停跑；手动管理指令不受总开关影响
- 动作失败不中断链（如踢人无内邀权限时自动跳过并记入告警错误信息）
- 旧版"监控处置"配置在升级时自动迁移为一条「广告监控（迁移）」规则
